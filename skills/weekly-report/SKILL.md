# 周报撰写指南

按以下流程为用户生成一份结构化周报，默认保存为 markdown 文件。

## 第一步：确认信息

1. 用 `get_current_time` 确认今天的日期，推算本周的起止日期（周一至周日）。
2. 询问用户本周做了什么（如果用户没有直接给出）。可提示用户从这些角度回忆：
   - 完成的任务与产出物
   - 进行中的事项与进度
   - 遇到的问题与需要的支持
   - 下周计划

## 第二步：生成骨架（可选）

如果用户希望快速开始，可以运行本技能的脚本生成一份空白骨架到当前工作目录：

```
execute_skill_script(skill_name="weekly-report", script_name="gen_skeleton.py",
                     script_args="--week 2026-W44 --output weekly_report_2026W44.md")
```

- `--week` 形如 `2026-W44`（ISO 周号）；不传则默认当前周
- `--output` 为输出文件名，默认 `weekly_report.md`；相对路径相对脚本所在目录（`scripts/`），脚本会打印解析后的绝对路径
- 脚本只创建文件不填写内容，由你（Agent）根据用户口述填充

## 第三步：填写内容

按以下模板组织周报（文件保存在沙箱内，用 `write_file` 写入）：

```markdown
# 周报（{起始日期} ~ {结束日期}）

## 本周完成
- [事项]：[结果/产出]

## 进行中
- [事项]：[当前进度，百分比或阶段]

## 问题与风险
- [问题描述]：[影响 + 需要的支持]

## 下周计划
- [计划事项]
```

## 注意事项

- 内容来自用户口述，**不要编造**用户没提过的进展。
- 每个条目一句话讲清"做了什么 + 结果是什么"，避免流水账。
- 用户说"简单点"时，去掉"问题与风险"和"下周计划"两个小节。
- 写完文件后向用户复述文件路径与内容摘要。
